# Security Policy

## Reporting

Report suspected vulnerabilities to ai@odei.ai.

Please include the affected repository, a concise technical description, impact, reproduction notes, and any evidence needed for triage. Do not probe live infrastructure, attempt persistence, access third-party data, or disclose details publicly before coordination.

## Scope

This repository is a curated public surface. Production credentials, private deployment automation, internal infrastructure code, and operator keys are intentionally not published here.

## Response

We review reports promptly and prioritize issues that demonstrate concrete impact against an in-scope public asset.
